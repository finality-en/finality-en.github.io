Finality Classes Guide

Choose your classes and earn permanent abilities for the whole season. This guide covers how to pick, unlock and switch classes, and what each one does.

Permanent abilities 1 default + 1 special Unlockable classes Daily KOTH rolls

Getting started

It takes about a minute.

Join the serverThe class menu opens on its own the first time you join. It stays open until you pick a class, and you can't be hurt while it's open.
Pick a default classLeft-click one of the default classes. Its ability switches on straight away and lasts the whole season, even through deaths and milk.
Unlock a special classSpecial classes sit on top of your default class, so you get both abilities. Win the daily KOTH event to get a Special Class Roll, spin it, and equip whatever you unlock from the same menu.

Your class slots

The menu title shows how many classes you have, for example (1/2) or (2/2).

🔥 Default class slot 1
⚡ Special class slot 2
➕ Second default with an Extra Class Token

Everyone starts with 2 slots: one default class and one special class. An Extra Class Token adds a third slot for a second default class, so your count becomes /3.

Special classes

Special classes glow in the menu and sit on top of your default class. You can have one at a time.

🔒

Special classes start LOCKED. Unlock them with a Special Class Roll from winning KOTH. Once unlocked they show UNLOCKED and you can equip them.

🪓

🎰 KOTH Special Class Roll

Win the daily KOTH event to get a Special Class Roll. Spin it to unlock a special class.

Win KOTHThe winner of each daily KOTH gets a Special Class Roll (a glowing nether star).
Right-click itA roulette spins through the special classes, slows down, and lands on one.
It's unlocked for the seasonThe class you land on is unlocked until the season ends, and the whole server sees what you rolled. Equip it from /class.

Switching special classes

Switching special classes is free. You don't need a token.

You click…What happens
A special class, with none equippedIt's equipped on top of your default class.
A different special classYou switch to it.
The special you already haveIt's unequipped.
⏱️

There's a short 5 second cooldown between changes.

Tokens

Special items that change your default class. Right-click to use them.

🟠

Class Reset Token

Item

Right-click, then confirm, to reset your default class and pick a new one straight away.

  • Your special class is kept
  • A green button confirms, a red one goes back
  • Uses one token
💜

Extra Class Token

Item

Right-click to add a second default class, so you could have Pharo, Ninja and a special at once.

  • Only default classes can be picked
  • It can't be one you already have
  • Your slots become /3

FAQ

Do I lose my ability when I die?

No. Class abilities come back automatically after death, milk or effect clears. The only exception is Berserker's bonus hearts, which reset on death.

Can I have two special classes?

No, you can only have one special class at a time. You can switch between special classes whenever you like, with a 5 second cooldown.

Why didn't my kill count for Berserker or Bloodlust?

Only real player kills count. Berserker uses the server's PvP stats, so kills the anti-farming system rejects don't give hearts.

I picked the wrong default class. What now?

Use a Class Reset Token. It resets your default class and keeps your special class.

How do I unlock special classes?

Win the daily KOTH event. The winner gets a Special Class Roll, which unlocks a random special class for the rest of the season.

What if I roll a class I already have?

Duplicates are lost, so that roll is used up. If you already own every special class, the roll won't let you use it, so save it for next season.

Do unlocked special classes last forever?

They last for the current season. When a new season starts, everyone starts fresh.

Do potions still work?

Yes. A stronger potion, such as Speed II on a Ninja, takes over while it lasts, and your class effect comes back when it runs out.
